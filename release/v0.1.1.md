## 修复

- **深色主题下整个管理页面不可读**（重要）：
  - 症状：深色主题里标题/列表/卡片/表单文字几乎看不见，只有彩色徽章可辨。
  - 根因：样式引用了宿主不存在的 `--dsh-*` CSS 变量，全部静默落回浅色主题的
    深色字面值，而背景回落 `transparent`，深色文字叠在宿主深色底上。
  - 修后行为：全部颜色改走宿主 design-platform alias token——文字
    `--dsw-alias-label-primary/secondary/tertiary/caption`、弹窗 `bg-layer-2`、
    填充 `bg-skeleton` / `interactive-bg-hover`、边框 `border-l3/l4`、遮罩
    `bg-mask-3`、品牌与状态 `brand/state-*`；状态徽章用 `color-mix` 从语义色
    派生半透明填充。浅色 `:root` 与深色 `body[data-ds-dark-theme]` 自动切换，
    无 token 的宿主回落浅色字面值保底。编辑器弹窗、输入框、下拉、单选框、
    placeholder、focus 边框同步适配。
