## 新增

- **运行历史 CRUD**：
  - rpc 新增 `delete-run` / `clear-runs` 端点与服务；queued / running
    记录拒绝删除，仅终态记录可删。
  - 运行历史行新增「删除记录」，任务卡新增「清空历史」入口。
- **runtime.notice 通知通道**：桥接失败在面板内以通知可见，替换编辑器
  局部 `setNotice` 静默路径——失败不再无声丢失。

## 修复

- **运行历史「打开会话」在 dsh 0.1.6-alpha.2 失效**：
  - 症状：点击运行记录的「打开会话」无反应/报错。
  - 根因：上游删除了 `ISessions.open`。
  - 修后行为：改走 `ctx.uiWorkspace.openSession` 官方导航路径。
- **目录选择器宿主回退链**：
  - 症状：桌面目录桥缺失/失效的环境（如部分宿主版本）无法选择目录。
  - 修后行为：桌面桥缺失/失效时回退宿主 OS 选择器
    `uiWorkspace.pickDirectory`；两桥皆缺时编辑器内联报错提示，
    不再静默失败。
